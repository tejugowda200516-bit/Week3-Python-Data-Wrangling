**Objective:** To clean, analyze, and visualize a dataset using Python and Pandas.

**Tools Used:** Python, Google Colab, Pandas, Matplotlib, and Seaborn.

6. Generated descriptive statistics using `df.describe()`.
7. Created a histogram to visualize calorie distribution.
8. Created a bar chart comparing average Pulse and Maxpulse.
9. Created a scatter plot to examine Duration versus Calories.
10. Calculated a correlation matrix and created a correlation heatmap.
11. Saved and downloaded the cleaned dataset as `cleaned_data.csv`.
